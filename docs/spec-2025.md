# Packet format 2025 (base F1 25)

Distilled wire spec for `packetFormat == 2025`, as implemented by
`src/f126/parser/spec_2025.py`.

**Source of truth:** the C headers in
[MacManley/f1-25-udp](https://github.com/MacManley/f1-25-udp) (`src/*.h`). Every
struct there is wrapped in `#pragma pack(push, 1)`, so the wire layout is
little-endian with **no padding and no alignment** — a Python `struct` format
string prefixed with `<` reproduces it exactly.

The sizes below are *derived* by `spec_2025.py` from its field tables at import
time, then pinned against these literals in
`tests/test_parser_2025.py::test_wire_size_matches_reference`. If a table and a
literal ever disagree, the test fails rather than the parser silently
misreading a live stream.

## Common shapes

| Item | Value |
| --- | --- |
| Header size | 29 B (identical in 2025 and 2026) |
| Car array length | **22** |
| Wheel array order | RL, RR, FL, FR (matches `types.WheelSet`) |
| Byte order | little-endian, packed, unaligned |

### PacketHeader (29 B) — `PHeader.h`

| Offset | Type | Field |
| --- | --- | --- |
| 0 | uint16 | `packetFormat` (2025) |
| 2 | uint8 | `gameYear` |
| 3 | uint8 | `gameMajorVersion` |
| 4 | uint8 | `gameMinorVersion` |
| 5 | uint8 | `packetVersion` |
| 6 | uint8 | `packetId` |
| 7 | uint64 | `sessionUID` |
| 15 | float | `sessionTime` |
| 19 | uint32 | `frameIdentifier` |
| 23 | uint32 | `overallFrameIdentifier` |
| 27 | uint8 | `playerCarIndex` |
| 28 | uint8 | `secondaryPlayerCarIndex` (255 = none) |

`gameMajorVersion` / `gameMinorVersion` are read but dropped: `types.PacketHeader`
does not carry them.

## Per-record layouts

Only the records the parser actually reads are expanded here; the skipped
packets are enumerated in `spec_2025.py` purely so their sizes stay derived.

### `CarMotionData` — 60 B (id 0)

`3×float` world position, `3×float` world velocity, `6×int16` forward/right
direction vectors, `3×float` g-force (lateral, longitudinal, vertical),
`3×float` yaw/pitch/roll.

The parser reads only the first 52 B (through `yaw`) and only for the player
car. **G-forces are float32 here** and are used unscaled — contrast 2026.

### `LapData` — 57 B (id 2)

`uint32` last lap ms, `uint32` current lap ms, then three
`(uint16 ms, uint8 minutes)` pairs for sector 1, sector 2 and the deltas to the
car ahead / race leader, `3×float` lap/total distance and safety-car delta,
then 14 uint8 status bytes through `resultStatus`, then a 11 B tail
(pit-lane timers, speed trap).

`types.CarLap` needs only the **first 46 B**, so the all-cars sweep is compiled
as `("<IIHBHBHBHBfff" + "B"*14 + "11x") * 22` — one `unpack_from` for the whole
packet, skipping 11 B per car.

Sector and delta times are reassembled as `minutes * 60000 + milliseconds`.

### `CarTelemetryData` — 60 B (id 6)

`uint16` speed, `3×float` throttle/steer/brake, `uint8` clutch, `int8` gear,
`uint16` RPM, `uint8` DRS, `uint8` rev-lights %, `uint16` rev-light bits,
`4×uint16` brake temps, `4×uint8` tyre surface temps, `4×uint8` tyre inner
temps, **`uint16` engine temperature**, `4×float` tyre pressures, `4×uint8`
surface types.

The player car is decoded in full; opponents contribute only the `uint16` speed
at offset 0, swept with `("<H" + "58x") * 22`.

### `CarStatusData` — 55 B (id 7)

5 uint8 assists/bias, `3×float` fuel, `2×uint16` RPM limits, `uint8` max gears,
`uint8` DRS allowed, `uint16` DRS activation distance, `3×uint8` compound/age,
`int8` FIA flags, `2×float` engine power (ICE, MGU-K), `float` ERS store,
`uint8` deploy mode, `2×float` ERS harvested (MGU-K, MGU-H), `float` ERS
deployed, `uint8` network paused.

`StatusView.ers_harvested_lap_j` is the **sum** of the MGU-K and MGU-H fields.

### `CarDamageData` — 46 B (id 10)

`4×float` tyre wear, then `4×uint8` each for tyre damage, brake damage and
blisters, 6 uint8 aero components, DRS/ERS fault flags, gearbox and engine
damage, 6 uint8 engine-component wear values, blown/seized flags.

### `ParticipantData` — 57 B (id 4)

`uint8` AI flag, **`uint8` driver id**, **`uint8` network id**, **`uint8` team
id**, `uint8` my-team, `uint8` race number, `uint8` nationality, `char[32]`
name, `uint8` telemetry visibility, `uint8` show-online-names, `uint16` tech
level, `uint8` platform, `uint8` colour count, `4×{uint8 r,g,b}` livery.

Names are NUL-terminated UTF-8 decoded with `errors="replace"`.

### `FinalClassificationData` — 46 B (id 8)

7 uint8 (position … result reason), `uint32` best lap ms, **`double`** total
race time, 3 uint8 penalty/stint counts, `3×uint8[8]` stint arrays.

### `LapHistoryData` — 14 B (id 11)

`uint32` lap time, three `(uint16 ms, uint8 minutes)` sector pairs, `uint8`
valid bit flags. Bit `0x01` is lap-valid; bits `0x02`/`0x04`/`0x08` are the
per-sector flags. `HistoryView.laps` exposes only bit 0.

### `TimeTrialDataSet` — 24 B (id 14)

`uint8` car idx, **`uint8` team id**, `4×uint32` lap and sector times, 6 uint8
assist/validity flags. `carIdx == 255` means the slot is unset and decodes to
`None`.

### Event union — 16 B body (id 3)

4 ASCII code bytes followed by a 12 B union. The widest member is `SpeedTrap`
(`uint8 + float + 3×uint8 + float` = 12 B), which sets the union width and
therefore the 45 B packet size.

Codes with no payload: `SSTA`, `SEND`, `DRSE`, `CHQF`, `LGOT`, `RDFL`.
Codes with payloads: `FTLP`, `RTMT`, `DRSD`, `TMPT`, `RCWN`, `PENA`, `SPTP`,
`STLG`, `DTSV`, `SGSV`, `FLBK`, `BUTN`, `OVTK`, `SCAR`, `COLL`.

`COLL` carries **2 bytes** in this format (both vehicle indices); the 2026 pack
adds a third `severity` byte.

Unrecognised codes decode to an `EventView` with an empty `details` rather than
an error, so a future game patch cannot break capture.

## Notes and gotchas

- `trackId` and `vehicleFiaFlags` are **int8**: `-1` arrives as `0xFF` and must
  be sign-extended (`"b"`, not `"B"`).
- `Session.trackTemperature` / `airTemperature` and the forecast temperature
  fields are likewise signed.
- The Session packet always transmits all 21 marshal zones and all 64 forecast
  slots; `numMarshalZones` / `numWeatherForecastSamples` say how many are
  meaningful. The parser truncates the forecast list accordingly.
- `SessionHistory` always transmits 100 lap slots; only `numLaps` are decoded.
